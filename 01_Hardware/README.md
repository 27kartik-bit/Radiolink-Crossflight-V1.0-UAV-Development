# UAV Hardware Components

This section documents the hardware components used in the Radiolink Crossflight V1.0 quadcopter project.

## Components

### 1. Flight Controller

Radiolink Crossflight V1.0.

### 2. Electronic Speed Controllers

SimonK 30A ESCs used for brushless motor speed control.

### 3. Brushless DC Motors

Motors used to generate the thrust required for quadcopter flight.

### 4. Power System

LiPo battery and power distribution system.

### 5. GPS Module

GPS integration for positioning and navigation support.
