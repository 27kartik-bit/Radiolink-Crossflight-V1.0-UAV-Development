# GPS Receiver and Navigation System

## 1. Overview

This section documents the GPS module integrated into the Radiolink Crossflight V1.0 quadcopter.

GPS technology enables a UAV to receive satellite-based positioning information, supporting navigation and location awareness.

## 2. GPS Module

**Component:** GPS Receiver Module

### Function

The GPS receiver obtains positioning information from available navigation satellites.

### Technical Role

* Satellite-based positioning.
* Providing location information to the flight control system.
* Supporting GPS-assisted navigation modes, when supported and configured.

## 3. System Integration

The GPS module forms part of the quadcopter's onboard electronics architecture.

Its integration involves:

* Physical installation.
* Electrical connection to the flight controller.
* Communication interface configuration.
* Verification of GPS connectivity and satellite reception.

## 4. Navigation Applications

GPS functionality can support:

* Position estimation.
* Navigation assistance.
* Position-hold functionality.
* Waypoint-based navigation, where supported and configured.
