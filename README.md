# Radiolink Crossflight V1.0 – Quadcopter Development

## Project Overview

This project involved the assembly, hardware integration and configuration of a quadcopter using the Radiolink Crossflight V1.0 flight controller.

The primary objective was to develop practical knowledge of UAV architecture, propulsion systems, electronic integration, flight controller configuration and ground control station operations.

## Hardware Components

| Component                    | Specification               |
| ---------------------------- | --------------------------- |
| Flight Controller            | Radiolink Crossflight V1.0  |
| Electronic Speed Controllers | SimonK 30A ESCs             |
| Motors                       | Brushless DC Motors         |
| Power System                 | LiPo Battery                |
| Ground Control Station       | Mission Planner             |
| Other Components             | GPS, RC Receiver, Telemetry |

*Additional specifications will be documented as verified.*

## Technical Work

### 1. Hardware Assembly

* Quadcopter frame assembly.
* Integration of brushless motors and ESCs.
* Installation of flight controller and supporting electronics.

### 2. Electrical Integration

* Power distribution system integration.
* ESC and motor connections.
* Integration of GPS and RC communication components.

### 3. Flight Controller Configuration

* Flight controller setup.
* Calibration and configuration using Mission Planner.
* Ground control station connectivity.

### 4. Testing and Troubleshooting

* Hardware connectivity checks.
* Motor and ESC system checks.
* Flight controller configuration verification.
* Troubleshooting of hardware and communication issues.
