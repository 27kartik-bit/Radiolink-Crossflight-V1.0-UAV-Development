# Mission Planner – UAV Configuration and Ground Control

## 1. Overview

This section documents the use of Mission Planner as a Ground Control Station (GCS) during the Radiolink Crossflight V1.0 quadcopter project.

Mission Planner was used to interact with the flight controller, perform system configuration and access ground control functionalities.

## 2. Software Used

**Software:** Mission Planner

**Application:** UAV Ground Control Station

## 3. Configuration and Setup

Mission Planner was used for flight controller configuration and system setup.

Activities included:

* Establishing communication with the flight controller.
* Accessing flight controller configuration settings.
* Performing available calibration procedures.
* Reviewing system parameters and configuration options.

## 4. Ground Control Station Operations

Mission Planner provides an interface for interacting with the UAV flight control system.

Relevant functionalities include:

* Flight controller communication.
* Sensor calibration interfaces.
* System status monitoring.
* Flight data visualisation.
* Configuration and parameter management.

## 5. System Monitoring

The Ground Control Station provides access to information relating to the UAV's operating status.

Relevant monitoring features include:

* GPS status.
* Sensor information.
* Flight controller status.
* Telemetry data, where available.

## 6. Technical Skills Developed

* Ground Control Station Operations.
* Flight Controller Configuration.
* UAV System Monitoring.
* Hardware and Software Interface Understanding.
* UAV Troubleshooting.

## 8. Project Scope

Mission Planner was used as a configuration and ground control tool.

No custom Mission Planner software or flight control firmware was developed as part of this project.
