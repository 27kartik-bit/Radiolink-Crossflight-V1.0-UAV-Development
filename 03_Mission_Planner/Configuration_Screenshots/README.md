# Mission Planner Configuration Screenshots

This folder contains screenshots documenting the use
of Mission Planner during the UAV project.

## Documentation Categories

### 1. Flight Controller Connection
Screenshots showing the connection between Mission
Planner and the flight controller.

### 2. Calibration
Screenshots of the calibration interfaces used
during system setup.

### 3. Configuration
Screenshots documenting available flight controller
configuration settings.

### 4. Flight Data
Screenshots showing available flight data and
system monitoring interfaces.

## Notes

Screenshots are included for technical documentation
and demonstration of Ground Control Station experience.
